# Transacform Partner (Vendor App Demo)

Aplikasi portal mitra vendor dan florist Transacform yang responsif untuk operasional florist toko dan kurir lapangan.

## Fitur Utama
- **Radar & SLA Pesanan Masuk (15 Menit)**
- **Kamera & Upload Hasil Jadi (HJ)**
- **Upload Hasil Lokasi (HL) Kurir**
- **Kalkulasi Saldo Dompet Vendor Instan**
- **Manajemen Pengguna Vendor (Admin & Staf Toko)**

## Deployment
Aplikasi ini dikonfigurasi dengan GitHub Actions untuk auto-deploy ke GitHub Pages setiap ada commit ke branch `main`:
